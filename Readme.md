# 🌍 Country Info Finder

Une mini application web qui vous permet de rechercher des informations sur n'importe quel pays en utilisant l'API [REST Countries](https://restcountries.com/).

## ✨ Fonctionnalités

- Recherche par nom de pays
- Affiche :
  - Le nom officiel du pays
  - La capitale
  - La population
  - La/les langue(s) officielle(s)
  - Le drapeau
